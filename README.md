# kanoodle-solver
A simple solver for the 2D Kanoodle puzzle, implemented in Haskell.
It places all puzzle pieces on the board using a recursive backtracking approach.

## Features
- Supports all rotations and reflections of the pieces

- Handles custom starting configurations

- Written in Haskell for clarity and functional style

## Purpose

A minimal project to explore backtracking and constraint-solving in a functional programming context.
